# 텐고쿠 워프 — TFC판 사용법

> Steam build 25767944 RC: [validation and limitations](BUILD-25767944-VALIDATION.md). File/engine tests completed; new-build live gameplay pending. / 새 빌드 파일·처리 엔진 검증 완료, 실게임 검증 전.

일반 텐고쿠 시작층을 51·101·201·301층 중 선택합니다.

이 배포물은 **TFC 전용판 tfc-v1.2.1-rc.1**입니다. 기존 독립 실행판은 별도 배포물이며 이 ZIP에 포함하지 않습니다.
릴리스의 `*-tfc-v1.2.1-rc.1.zip` 첨부 파일을 받으세요. GitHub의 Source code ZIP은 전용 배포물이 아닙니다.
Node.js 22.13 이상과 TFC Installer 2.5.6.0이 필요합니다. 대응 빌드: 25386710.
게임을 종료하고 세이브를 별도로 백업하세요.
기존 독립 실행판을 사용했다면 해당 도구로 먼저 제거하세요. 두 방식을 혼용하지 마세요.

## 처음 설치

1. 원본 폴더의 **run-tfc.bat → 5번 호환 TFC 패키지 준비**를 실행하세요.
2. 출력된 **새 준비 폴더**를 TFC에서 바로 적용하세요.
3. **준비 폴더의 run-tfc.bat → 1번 설치 마무리**를 실행하세요.
4. 완료 안내가 나오면 게임을 실행하세요.

준비 후 게임 파일이나 다른 모드가 바뀌었다면 원본 폴더에서 5번으로 다시 준비하세요.
원본 패치를 TFC에 바로 넣으면 외부 변경 보존 검사를 거치지 않습니다.
이번 프리릴리스에 포함된 절차입니다. 파일·실제 처리 엔진 검증 완료 / GUI·실게임 재검증은 미완료입니다.

`run-tfc.bat`은 게임 설치 폴더 또는 `BrgGame-Steam.exe` 경로를 물어봅니다.
1번이 필요한 연결·보조 기능을 함께 처리하므로 별도로 해시 연결을 또 할 필요는 없습니다.

## 제거

1. 게임 종료 후 TFC에서 이 모드를 제거하세요.
2. 같은 모드 폴더의 **run-tfc.bat → 2번 제거 마무리**를 실행하세요.

TFC의 **Uninstall all**로 전체 제거했다면, 수정된 네 TFC 도구 중 어느 것이든
**2번 제거 마무리**를 한 번 실행하면 됩니다. 가드·워프·M2G·자판기의
모든 검증 대상 UPK 기능이 OFF인지 확인한 뒤 워프·자판기 보조 기능도 끄고,
도구가 기록한 재료 상품만 삭제합니다. UPK·세이브·무관한 EXE/DB 변경은
유지하며 같은 작업을 다시 실행해도 안전합니다. 일부 기능만 뜻밖에 유실되거나
알 수 없는 충돌이 있으면 계속 차단합니다. 설치·일반 연결 갱신에는 이 예외가 없습니다.


## 문제가 있을 때만

호환 복구:

- Nico의 파일 검사 OFF는 그대로 유지합니다. 알 수 없는 EXE 명령어는 계속 차단합니다.
- TFC가 `Gap ... between two disk data blocks`로 거부하면
  **4번 고급 → 5번 UPK 블록 간격 복구**를 실행한 뒤 다시 5번 준비부터 진행하세요.
  이 별도 복구는 EXE·UPK를 백업하고 압축 블록 위치만 바꿉니다. 세이브·DB는 변경하지 않습니다.
- 복구 도중 중단됐다면 **4번 고급 → 3번 중단 작업 복구**를 먼저 실행하세요.
- 다른 관리자가 이전 원본을 다시 적용해 설정이 되돌아갔다면 해당 프리셋만
  새로 준비·TFC 적용·마무리하세요. 오래된 전체 UPK 백업을 덮어쓰지 마세요.
- 준비·설치 이후 다른 모드를 변경했다면 새 패키지를 준비하세요.
  설치 마무리는 다른 검증 대상 함수의 유실도 검사합니다.

Nico가 지원하지 않는 워프 맵 테이블 추가는 TFC로 설치해야 합니다.
파일 복사본에서 실제 Nico·TFC 엔진으로 검증했으며 GUI·실게임 재검증은 남아 있습니다.

`run-tfc.bat → 3번`: 연결 상태 확인.
`run-tfc.bat → 4번 고급 메뉴`: 다른 TFC 패치 변경 후 연결 갱신·이전 EXE/DB 설정 복원·중단 작업 복구.
다른 TFC 모드로 UPK가 바뀌었다면 고급 메뉴의 1번으로 연결을 갱신하세요.

백업은 게임 폴더의 상위 **LET-IT-DIE-TFC-backups**에 있습니다.
UPK 복원은 TFC, EXE·DB 설정 복원은 보조 도구가 담당합니다. 구매·데칼·탄약 등 세이브 결과는 되돌리지 않습니다.
`LID-TFC-State`와 백업을 수동 삭제하지 마세요. 같은 UPK 객체를 바꾸는 외부 모드와는 충돌할 수 있습니다.
## 호환성 보완 — 워프 명령어 구간 검증

빌드 25386710의 TFC 보조 도구에서 BrgGame 함수 전체 해시 대신 워프 함수
두 개의 식별 정보·크기·헤더·명령어 문맥을 확인합니다. 같은 함수 안의
Faster Drops 등 무관한 명령어 변경을 허용하지만, 워프 명령어가 충돌하면
네이티브 적용을 차단합니다. 맵·자판기 필수 함수 검증과 복구 보호는 유지합니다.

공통 설치의 해시 연결을 처리하는 네 TFC 보조 도구에 같은 읽기 전용 검증을
포함했습니다. 다른 모드를 자동 활성화하지 않으며, UPK·세이브를 쓰지 않습니다.
이 변경은 tfc-v1.2.0-rc.1에 포함됩니다. GUI·실게임 재검증은 미완료입니다.

5번 준비 절차는 검증된 동일 길이 명령어 변경에서 무관한 바이트를 보존합니다.
소유 명령어·필수 문맥·구조가 충돌하면 중단합니다. 길이가 달라지는 함수는
검증된 본문만 허용하며 임의로 명령어 위치를 추측하지 않습니다.
설치 후에는 병합한 본문과 등록된 기능 상태를 확인한 뒤 EXE/DB를 처리합니다.
외부 TFC 설치기의 직접 적용을 통제할 수는 없으므로 준비 직후 적용하세요.
