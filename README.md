# LET IT DIE 텐고쿠 100층 워프 도구

LET IT DIE 5.0.1.0 Steam 오프라인판의 메인 엘리베이터에 100층, 200층, 300층 체크포인트를 추가하는 실험적 패치/복원 도구입니다.

## 작동 방식

원래 100·200·300층은 무작위 전투/보스 영역이라 엘리베이터 맵 유닛이 없습니다. 단순히 엘리베이터 정차 ID만 추가하면 검은 화면, 잘못된 스폰 또는 진행 불능이 생길 수 있습니다.

이 도구는 자연 진행용 원본 층을 덮어쓰지 않습니다. 같은 층 번호에 엘리베이터 전용 체크포인트 영역을 별도로 만들고 다음 데이터를 함께 연결합니다.

- 51층에서 검증된 `HEAVEN_ELEVATOR`, `HEAVEN_START`, `HEAVEN_GOAL_V01` 맵 유닛
- 100→101, 200→201, 300→301층 상행 에스컬레이터
- 이전 층으로 내려가는 하행 에스컬레이터
- 메인 엘리베이터 정차 항목과 세이브의 `soul.openelvflr` 해금 항목

자연 진행으로 100·200·300층에 도착하면 기존 전투/보스 층이 유지됩니다. 대기실 메인 엘리베이터에서 선택했을 때만 전용 체크포인트로 들어가도록 데이터를 분리했습니다.

## 현재 상태

DB 구조, 연결 개수, SQLite 무결성, 세이브 재압축과 적용/제거 왕복은 자동 검증합니다. 실제 게임에서의 첫 진입은 아직 실험 단계이므로 반드시 자동 백업을 보관하세요. 첫 테스트는 귀중한 장비를 소지하지 않은 파이터로 권장합니다.

## 사용법

1. LET IT DIE를 완전히 종료합니다.
2. Node.js 22.5 이상을 설치합니다.
3. `run.bat`을 실행합니다. `masters.db` 수정 권한 때문에 관리자 권한으로 다시 열립니다.
4. `100·200·300층 체크포인트 워프 적용`을 선택합니다.
5. 게임을 실행하고 대기실 메인 엘리베이터 목록을 확인합니다.

자동 탐색에 실패하면 게임 설치 폴더와 세이브 파일을 직접 입력하거나 창으로 끌어놓을 수 있습니다. Steam을 다른 드라이브나 임의 폴더에 설치해도 지원합니다.

## 복원

- `워프 패치 제거`: 도구가 추가한 DB 행과 세이브 해금 ID만 제거합니다. 이후 다른 도구로 바꾼 값은 유지됩니다.
- `최신 전체 백업 복원`: 적용 전 `masters.db`와 세이브를 한 세트로 되돌립니다. 패치 이후 다른 도구로 바꾼 DB/세이브 값도 함께 되돌아갈 수 있습니다.
- 모든 적용·제거 전에 `backups` 폴더에 SHA-256 검증 가능한 백업 세트를 만듭니다.

## 명령행

```text
node --no-warnings lid-tengoku-warp.js status --game "C:\...\LET IT DIE" --save "C:\...\123.sav"
node --no-warnings lid-tengoku-warp.js apply --yes --game "C:\...\LET IT DIE" --save "C:\...\123.sav"
node --no-warnings lid-tengoku-warp.js remove --yes --game "C:\...\LET IT DIE" --save "C:\...\123.sav"
node --no-warnings lid-tengoku-warp.js restore --yes --backup "C:\...\backups\백업폴더" --game "C:\...\LET IT DIE" --save "C:\...\123.sav"
```

## 주의

- LET IT DIE 5.0.1.0 Steam 오프라인판의 현재 `masters.db` 구조를 대상으로 합니다.
- 게임 실행 중에는 적용·제거·복원을 차단합니다.
- 온라인 서비스 또는 다른 버전에는 사용하지 마세요.
- 게임 업데이트나 파일 무결성 검사는 `masters.db`를 원본으로 되돌릴 수 있습니다.
- 이 프로젝트는 비공식 팬 도구이며 게임 제작사·배급사와 관련이 없습니다.
